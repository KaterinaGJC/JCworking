## 二、两个技术取舍（重要）

### 1. 撕纸卡片为什么没有外阴影？

`clip-path` 会把元素自己的 `box-shadow` **一起裁掉**，阴影会消失在被裁掉的区域里。
给父元素加 `filter: drop-shadow()` 能把阴影裁成撕纸形状，但 `filter` 会让父元素变成定位包含块，风险大于收益。

所以这一版用**三件事**替代外阴影：

1. 底部内阴影 + 底边渐变（模拟纸张厚度）
2. `inset 0 0 0 1.5px rgba(74,69,67,.06)` 的极淡纸边
3. 卡片之间靠**旋转错位**产生的重叠，本身就形成层叠感

如果需要更强的"浮起来"效果，正确做法是给卡片套一层不裁剪的 `div`（`filter: drop-shadow()` 放在外层），这需要改 DOM —— 打样阶段先不做。

### 2. 字体：本地打包（2026-10-26 改）

第一版靠系统字体兜底，结果"文字很平"——参考图那种细宋/花体感，系统字体根本给不出来。所以改成**本地打包**：

| 用途 | 字体 | 体积 | 加载方式 |
|---|---|---|---|
| 中文标题 / 卡片标题 / 日期 / 页码 | **思源宋体 Noto Serif SC 400** | 3.04 MB（101 个 `unicode-range` 子集） | 按需：用到哪个子集才下哪个；SW 运行时缓存 |
| 拉丁花体（开屏标语、页码 01–05） | **Caveat 600** | 50 KB | 进 SW 预缓存 |
| 拉丁衬线斜体（日期圆数字） | **Playfair Display Italic** | 23 KB | 进 SW 预缓存 |

**正文（列表、输入框）还是系统无衬线** —— 这不是偷懒：15px 的中文宋体在手机小字下会发糊，正文用无衬线、标题用宋体，层次反而更清楚。

**依然离线、依然零 CDN**：字体文件都在 `app/fonts/`，测试里有一条专门守着"CSS 里不许出现 fonts.googleapis / gstatic"。

## 四、各模块实现要点

### 开屏（`index.html` 的 `.splash` + `main.js` 的 `playSplash()`）
- 两片纸（`.half.l` / `.half.r`）各带方格纸纹理，从中间向两侧 `rotateY(±102deg)` 翻开
- 中间一条和纸胶带（`.seam`）先撕开（420ms），随后纸页才动（240ms 延迟 + 980ms）
- 中央 `little blue today` 手写标语淡入淡出
- **同一次会话只播一次**（`sessionStorage`），`prefers-reduced-motion` 下**直接不播**
- `.splash` 是 `pointer-events:none`，动画期间页面照常可点，绝不挡操作

### 首页（`.home-body`）
- `hero` 压到 **≤72px**（这条有验收测试 v2-11 把着，别撑高）：日期 18.5px 楷体 + 摘要单行 + 右侧虚线日期圆
- 三张便签 `data-card="plan|memo|fun"`：撕边 + 胶带 + 各自旋转角；备忘卡换蓝调纸、胶带换粉色
- 计划卡内部（待安排 / 时间轴 / 已完成）**不做成便签**，只用手写小标题 + 蓝色小划线分隔
- 勾选框改成 6px 圆角方框，完成后填充薄荷绿

### 记录（`.post-body`）
- 记录卡 = 便签纸 + 顶部横向胶带（奇偶蓝/黄），上面留 26px 给胶带，不压正文
- 底部信息行用虚线分隔，点赞按钮做成胶囊贴纸（点过变粉）
- 输入区是一张"待写的纸"，正文框只有一条下划线

## 五、五套扩展（第二版已补齐）

规范里点名、第一版没做的五样，现在都做了：

| 项 | 实现方式 | 数据/结构 |
|---|---|---|
| **① 拍立得相框** | 记录页配图改成「暖白粗边 + 底部留白 24px + 轻微倾斜（奇 -1.4°/偶 +1.6°）」；纯 CSS | 无改动 |
| **② 蝴蝶结 / 贴纸** | 蝴蝶结画在首页 hero 右下（内联 SVG 的 data URI 做背景，**不新增 DOM**）；心情卡标题角上一枚小星星 | 无改动 |
| **③ 蓝调心情记录** | 首页新增「今天的心情」便签卡：5 个圆形心情圈（开心/难过/生气/平静/累）+ 一句手写话 | 新增 `app/js/core/mood.js`；**存 meta 表，不升 DB 版本** |
| **④ 页码贴纸切页** | 底部 5 个标签变成带 `01–05` 编号的贴纸（选中翘起 2px）；页面切换用 `slap` 动画：新便签从下方贴上并回正（420ms） | `index.html` 加 `data-num` |
| **⑤ 夜间纸（深色）** | 不是"变黑"，是换一批深色纸：冷灰蓝底 `#1B2230` + 夜间纸 `#2B3242` + 米白字 `#E8E0D5`，胶带/贴纸同步压暗，撕边与层叠全部保留 | 覆盖 `[data-theme="dark"]` |

### 为什么心情用 meta 表而不是新建数据表

新增一张表就要把 DB 版本 3→4→5，**每一次迁移都有丢数据的风险**，而心情只是"一天一个圈 + 一句话"，量极小。
放在 `meta`（`mood:YYYY-MM-DD`）里：不迁移、备份自动带上、合并导入也天然支持。

### 五套的验证（`tests/v2/19-scrapbook-ui.test.mjs`，17 条断言）

- 心情：5 个圈 → 点击落库到 meta → 选中态正确 → **刷新后仍选中** → 手写句非空
- 页码：5 个标签的 `::before` 内容必须是 `01`–`05`
- 切页：`.page` 的 `animation-name` 必须是 `slap`，且时长 < 500ms
- 拍立得：下边框比上边框厚 8px 以上、白边不能是纯白、相纸带倾斜
- 夜间纸：底色亮度降 0.3 以上、纸张变暗但**不能接近纯黑**、文字变浅
- 顺带守住 C-01：首页仍不含"教培/一对一/小班"

### 1. 四屏都换皮了

| 屏幕 | 做法 | 特别注意 |
|---|---|---|
| **教培课表** | **极简版（2026-10-26 重做）**：纯平纸色 + 1px 细线 + 无渐变/无胶带/无投影；表头靠字重区分，今天只变色不高亮；课块是平色小方块（一对一淡蓝、小班淡黄） | 课表一天要看很多次，是工具不是装饰。之前的渐变表头有"玻璃感"，太花，已全部去掉 |
| **游戏娱乐** | 分区卡片变成便签纸、游戏卡变拍立得式小卡（轻微交替倾斜）、分段控件与标签变粉彩胶囊 | 自动生成的封面是**高饱和色**（违反规范），用 `filter:saturate(.18) brightness(1.34)` 压成"老照片"质感，保留各自色相 |
| **快速备忘** | 便签保留 8 种颜色，但换成撕纸 + 交替倾斜 + 顶部小胶带；输入框变成"横线纸" | 3 种撕边/角度轮换，避免所有便签长得一模一样 |
| **数据与设置** | 长列表卡片改成**整齐的圆角纸**（不撕边）；顶部统计数字用衬线斜体 | 长列表用撕边会把右边缘切得参差，反而难读 |

### 2. 心情历史条

首页心情卡底部新增**最近 7 天**：周几 + 一颗小圆点，记过的显示当天心情的颜色，今天带一圈高亮。
点心情后**今天那颗点立刻变实心**（不用刷新）。

### 3. 记录页多图 2×2 拼贴

≥2 张图时变成两列网格；单图占满整行；每张图仍保留拍立得白边（按你之前的要求：**摆正，不倾斜**）。

### 4. 页面切换：放弃了原生 View Transitions

原本想用 `document.startViewTransition` 做"旧卡淡出 + 新卡贴上"，DOM 不用改、效果最好。**实测不行**：

> 过渡快照层会盖住页面并吞掉点击 —— 动画那 400ms 内点输入框聚焦不了、点按钮没反应。
> 给 `::view-transition*` 加 `pointer-events:none` 也压不住（`elementFromPoint` 直接返回 `html`）。

对一个"随手就点"的个人 App 这是硬伤，所以**退回 CSS 的 slap 动画**（新便签从下方贴上并回正，420ms）。
测试里专门留了一条防回归：切页后**立刻**点输入框，必须能聚焦。

## 九、第四批：月历 / 心情月度回顾 / 堆叠 / 减负（2026-10-26）

### 1. 首页月历

参考图那种"手账里的月历"：

- 标题：`10月`（宋体）+ `October`（Playfair 斜体）+ 年份小字
- 右上：`‹` `›` 翻月 + `今天`（已在本月时自动变淡）
- 星期表头跟随「一周从哪天开始」设置
- 日期格：今天=粉彩蓝圆角块；**有任务的日期底部一个小点**；**有心情的日期右上角一颗心情色点**；非本月日期淡化
- 点任意日期 → **下面的「今日计划」卡直接切到那天**（`plan.js` 新增 `setPlanDate/getPlanDate`）
- 底部：本月心情小结（开心 2 / 难过 1 / 平静 1 …），没有记录时显示"这个月还没记心情"

### 2. 心情月度回顾

新增 `moodMapOfMonth(year, month)`（给月历打点）和 `moodStats(from, to)`（按月统计各心情天数），
都读 meta 表，不新增数据结构。

### 3. 卡片堆叠（旧纸滑走）

**没有复制旧 DOM**——那会让页面里同时存在两份 `class`，测试和读屏都会读到"两个首页"。
改成在 `.page::before` 画一张纸片：换页时这张"上一张纸"从底部滑走并淡出，新页面 slap 贴上来。
视觉上是堆叠，DOM 上永远只有一份。

### 4. 减负两处

- **课表空格子的 ＋ 默认隐藏**（opacity 0），改成**点格子任意位置就能加课**（schedule.js 里做了委托，不依赖按钮本身）
- **底部标签**：去掉整块选中底色和上浮位移，页码只在选中项出现，选中提示改成底部一条 2px 细线；图标线宽 1.55→1.95 只在选中时加粗

### 5. 顺手修的一个真 bug

纸面高光层（`.card::before`）原本盖在文字上面，导致卡片"蒙了一层雾"——
月历这种大面积白底一放上去就露馅了。改成 `z-index:-1` + 卡片 `isolation:isolate`，
让高光落到内容下方（首页卡片、记录卡、说明卡三处同修）。
