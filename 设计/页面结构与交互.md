# 景臣的个人工作生活 App —— 页面结构与交互设计（v1）

> 形态：安卓手机上的网页应用（PWA），加到桌面使用，离线可用，数据只存本机。
> 本文只定"长什么样、点下去发生什么"，不含代码。

---

## 1. 信息架构

### 导航方式

底部 5 个标签 + 首页右上角齿轮进设置。

```
┌─────────────────────────────┐
│  ☰ 标题               ⚙     │  ← 顶栏：左标题，右设置
│                             │
│        （页面内容）           │
│                             │
├─────────────────────────────┤
│  🏠     📋     🗓     🎮     📝  │  ← 底部 5 标签
│ 首页   计划   课表   娱乐   备忘  │
└─────────────────────────────┘
```

- 为什么不把"设置"放底部：访问频率低，5 个标签在手机上已经是拇指舒适的上限。
- 所有页面共用顶栏；顶栏右侧固定一枚 `＋`，点开是**当前页面**的新增入口（设置页除外）。

### 页面清单

| 编号 | 页面 | 入口 |
|---|---|---|
| P0 | 首页总览 | 标签 1 |
| P1 | 今日计划 | 标签 2 |
| P2 | 教培课表（周视图） | 标签 3 |
| P2a | 课次详情（记录一节课） | 点 P2 的课卡 |
| P2b | 学生列表 | P2 右上「学生」 |
| P2c | 学生档案（历史课次） | 点 P2b 某个学生 |
| P3 | 游戏娱乐 | 标签 4（内含 4 个分区） |
| P4 | 快速备忘 | 标签 5 |
| P5 | 数据与设置 | 首页右上齿轮 |

层级只有两层（列表 → 详情），不出现第三层，返回一律「手机返回键 / 顶栏左箭头」。

## 2. 全局交互规范（所有页面统一）

| 规则 | 做法 | 原因 |
|---|---|---|
| **保存** | 没有"保存"按钮。输入即存（停止输入 0.3 秒或离开输入框就写入） | 手机上手忙，忘了按保存就丢数据 |
| **保存反馈** | 顶栏右侧出现极小的「已保存 · 刚刚」，2 秒后淡出 | 让人放心，又不打扰 |
| **删除** | 一律先确认或给撤销机会：重要条目（课次、学生）弹确认；轻量条目（便签、待办）删掉后底部浮出「已删除 · 撤销」保留 5 秒 | 手机误触太容易 |
| **空状态** | 一句话说清 + 一个动作按钮，不画插画 | 例：「今天还没有安排 —— ＋ 加一条」 |
| **触控尺寸** | 所有可点区域不小于 44×44 | 拇指点击准确率 |
| **主操作位置** | 新增、完成、标记已上等高频操作放在屏幕**下半部** | 单手可达 |
| **首次使用** | 每个模块第一次打开时，页面顶部显示一张可关闭的提示卡，说明这块是干什么的 | 六个模块各有各的玩法，需要引导 |

## 3. 首页总览（P0）

### 版面（从上到下）

```
┌─────────────────────────────┐
│ 10月25日 周六           ⚙   │
│ 今天 3 件事没做完            │
├─────────────────────────────┤
│ 📋 今日计划          3/7  ▸ │
│  ○ 09:00 备下午的课         │
│  ○ 14:00 交季度总结         │
│  ○ 睡前 读 20 页            │
├─────────────────────────────┤
│ 📝 快速备忘              ▸ │
│  买电池 · 10分钟前          │
│  问一下周四调课 · 1小时前    │
│ ┌─────────────────────────┐ │
│ │ 记点什么…            ＋  │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ 🎮 游戏娱乐              ▸ │
│  ⏰ 明日方舟·危机合约 还剩1天 │
│  📺 芙莉莲 第 8 集 今天更新   │
│  ⭐ 最近：通关《星露谷》…     │
└─────────────────────────────┘
```

### 细节

- **顶部一句话**：不是固定文案，而是当天真实情况的汇总（"今天 3 件事没做完" / "今天没有安排" / "有 1 个活动明天截止"）。
- **今日计划卡**：显示 `已完成/总数` + 未完成的前 3 条。点卡片进计划页。
- **备忘卡**：最新 2 条 + 一个**就地输入框**，打完字按回车直接存，不用跳页。这是首页唯一能直接写入的地方，因为"快记"必须快。
- **游戏娱乐卡**：只放三类动态里**今天相关的**——今天/明天到期的活动、今天更新的追更、最近一条体验记录。没有就不显示该行，卡片自动变矮。
- **首页绝不出现教培课表的任何内容**（按你的要求）。
- 卡片顺序固定，第一版不支持拖动排序。

## 4. 今日计划（P1）

### 版面

```
┌─────────────────────────────┐
│  ‹   10月25日 周六   ›  今天 │
├─────────────────────────────┤
│ 待安排                      │
│  ○ 交季度总结                │
│  ○ 读 20 页                 │
├─────────────────────────────┤
│ 09:00  ○ 备下午的课          │
│ 14:00  ○ 联系家长            │
│ 20:00  ● 买菜          (完成)│
├─────────────────────────────┤
│ 已完成 (1)              ▾   │
└─────────────────────────────┘
                          ＋
```

### 交互

- **切日期**：顶部左右箭头逐日切换；点中间日期弹出月历直接跳。
- **两个区**：上面「待安排」（没有具体时间的），下面按时间轴排（有时间的）。有时间的排在前面更像日程，但"待安排"放顶部方便随手加。
- **新增**：点 `＋` → 从底部升起一个输入条：一个标题输入框 + 「加时间」按钮（可选）。默认不加时间，回车即存，可以连续加。
- **完成**：点左侧圆圈 → 划线、变灰、0.4 秒后滑到「已完成」区。再点一次可撤销。
- **编辑**：点标题文字进编辑（标题、时间、备注）。
- **排序**：长按条目可拖动改顺序；有时间段的条目自动按时间排，不参与拖动。
- **重复**：编辑里有「重复」选项——不重复 / 每天 / 每周（选周几）。第一版就这三种。
- **结转昨天的未完成**：当天第一次打开计划页时，如果昨天有未完成项，顶部出现一条提示：
  「昨天有 3 项没做完 → [转到今天] [不用了]」
  选"转到今天"则把这些项复制到今天（原日期保留记录）。不选就当天不再提示。

## 5. 教培课表（P2 / P2a / P2b / P2c）

> 核心区分：**整节课共用的记录** vs **每个学生各一份的记录**。

### 5.1 周视图（P2）

```
┌─────────────────────────────┐
│ ‹   10/21 - 10/27   ›  今天  │
│                       学生 ▸ │
├─────────────────────────────┤
│ 周六 10/25                  │
│ ┌─────────────────────────┐ │
│ │09:00-10:30  一对一   ●  │ │
│ │王小明                    │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │14:00-15:30  小班    ●   │ │
│ │李雷、韩梅梅 +2           │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ 周日 10/26  没有课           │
└─────────────────────────────┘
```

- **纵向按天分组**，不做 7 列网格：手机屏幕窄，一节课要同时显示时间、人数、学生姓名，7 列会挤成豆腐块。
- 每天一组，日期条上显示 `周六 10/25`；没课的日子显示"没有课"，保持时间连续感。
- **课卡信息**：时间段 · 类型标签（一对一/小班）· 状态点 · 学生姓名（超过 2 人显示"李雷、韩梅梅 +2"）。
- **状态点颜色**：灰=未上，绿=已上，橙=请假，蓝=补课。
- **点课卡** → 进入课次详情（P2a）。
- 右上「学生」→ 学生列表（P2b）。
- `＋` → 新建一节课（见 5.2）。

### 5.2 新建一节课

从底部升起表单：

1. 先选类型：**[一对一] [小班]**（两个大按钮，默认上次用过的）
2. 学生姓名：一个输入框，边打边从历史姓名里给建议（点一下即填）。小班可点「＋ 再加一个学生」继续加。
3. 日期 + 开始时间 + 时长（默认 90 分钟，可改）
4. 重复：不重复 / 每周（选周几）—— 教培的课一般是固定周次，默认"每周"并把本周其余同时间自动带出。
5. 保存 → 回到周视图，新卡出现。

### 5.3 课次详情（P2a）—— 最重要的页面

```
┌─────────────────────────────┐
│ ‹   10月25日 09:00-10:30     │
│     一对一           已上 ▾  │
├─────────────────────────────┤
│ 学生                        │
│ ┌─────────────────────────┐ │
│ │ 王小明        [很好▾]    │ │
│ │ 状态备注：函数概念清楚…    │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ 本节课主要内容               │
│ ┌─────────────────────────┐ │
│ │ 讲了二次函数的顶点式，     │ │
│ │ 练了 8 道配方法…          │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ 布置的作业                   │
│ ┌─────────────────────────┐ │
│ │ 练习册 P32-34，错的题重做  │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│   [ 标记已上课 ]            │
└─────────────────────────────┘
```

**区块说明**

| 区块 | 内容 | 归属 |
|---|---|---|
| 头部 | 日期、时间段、类型；右侧状态可改（未上/已上/请假/补课） | 整节课 |
| 学生区 | 一人一行：姓名（可点开编辑）、学习状态（快捷标签：很好/正常/需加强/待观察 + 备注）、该生考勤 | 每人一份 |
| 本节课主要内容 | 多行文本 | 整节课 |
| 布置的作业 | 多行文本 | 整节课 |
| 底部大按钮 | 「标记已上课」，点了状态转绿并轻微震动反馈 | 整节课 |

**小班时**：学生区变成可滚动的名单，每行右侧有 `▾` 展开写该生状态与备注；底部「＋ 加一个学生」。

**文本区交互**：默认显示 3 行高度，点了自动展开到半屏编辑，方便手机上打字；不是弹窗，避免键盘把内容遮住。

### 5.4 学生列表（P2b）与档案（P2c）

```
┌─────────────────────────────┐
│ ‹  学生                     │
├─────────────────────────────┤
│ 王小明      已上 12 节  ▸   │
│ 李雷        已上 8 节   ▸   │
│ 韩梅梅      已上 3 节   ▸   │
└─────────────────────────────┘
```

点进学生档案：

```
┌─────────────────────────────┐
│ ‹  王小明                    │
│ 累计 12 节 · 最近 10月25日    │
├─────────────────────────────┤
│ 10/25  一对一  已上  [很好]  │
│   内容：二次函数顶点式…       │
│   作业：练习册 P32-34        │
├─────────────────────────────┤
│ 10/18  一对一  已上  [正常]  │
│   内容：一次函数复习…         │
└─────────────────────────────┘
```

- 时间倒序，每张卡就是一次课的内容摘要 + 作业 + 当时的状态标签。
- 点卡片进那次课的详情，可补记。
- 列表里姓名旁显示"已上 N 节"，一眼看到这个学生上了多少。

## 6. 游戏娱乐（P3）

顶部分段切换四个分区，下面各自一套内容。

```
┌─────────────────────────────┐
│ 游戏娱乐                    │
│ [游戏库][活动][追更][体验]   │
├─────────────────────────────┤
│         （对应分区）         │
└─────────────────────────────┘
```

### 6.1 游戏库

- 按状态分三组，可折叠：**在玩 / 想玩 / 已通关**
- 每张卡：游戏名、平台标签（PC/主机/手机）、评分（★1-5）、一句进度或备注
- 点卡 → 底部升起编辑面板：名称、平台、状态、评分、备注
- 卡片上放一个「状态流转」快捷操作：
  - 在玩 → `[通关了]`
  - 想玩 → `[开始玩]`
  - 已通关 → 可改回在玩
- `＋`：加一款游戏

### 6.2 活动日程

- 列表按截止时间从近到远排，分三段：**即将到期（≤3 天，红色）/ 进行中 / 已结束**
- 卡片：游戏名 · 活动名 · `还剩 2 天`（≤1 天用红色并加粗）
- 卡片右上角可勾「已完成」→ 移到已结束区（避免刷屏）
- `＋`：游戏名（可从游戏库选）、活动名、截止日期、备注
- 不做自动循环刷新计算，只按截止日提醒；需要周期就在备注里写清楚。

### 6.3 追更表

- 列表：番名 / 每周几更新 / `看到第 8 集` / 共几集（可选）
- **今天更新的排最上面并高亮**；明天更新的带一个小标记
- 卡片右侧一个 `+1 集` 按钮，点一次集数加一（这是最高频操作，放右手位置）
- 全部看完的自动沉到底部「已看完」
- `＋`：番名、更新星期、总集数、当前集数

### 6.4 体验记录（观影 / 游戏体验）

- 时间倒序的卡片流，像日记
- 卡片正面：作品名、类型标签（游戏/电影/剧/番）、评分星星、日期的前 3 行正文
- 点卡片 → 全屏阅读/编辑（正文可写长，字体稍大，行距宽，适合回想时写）
- `＋`：作品名、类型、评分、可选进度（看到第几集 / 玩到哪 / 已通关）、正文
- 顶部可按类型筛选、可搜索

## 7. 快速备忘（P4）

```
┌─────────────────────────────┐
│ 快速备忘              🔍    │
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │ 写点什么…          存   │ │  ← 自动聚焦
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ ┌───────────┐ ┌───────────┐ │
│ │📌 买电池   │ │ 问一下周四  │ │
│ │ 10:20     │ │ 调课的事    │ │
│ └───────────┘ │ 昨天 18:03  │ │
│               └───────────┘ │
└─────────────────────────────┘
```

- **打开就自动聚焦输入框**，键盘直接弹出——这是"快速"的全部意义。
- 输入 → 按「存」或回车 → 便签立即出现在下面，输入框清空，焦点留原地（方便连着记几条）。
- **便签墙**：两列瀑布流，颜色 4 选 1（黄/蓝/绿/粉，默认黄），置顶的带 📌。
- **操作**（点便签打开小菜单）：
  - 编辑
  - 颜色
  - 置顶 / 取消置顶
  - 设为今日计划（复制一条待办到计划页，便签本身保留）
  - 删除（左滑也行，删后 5 秒可撤销）
- 顶部搜索框按内容搜。
- 首页显示最新 2 条，用的是同一份数据。

## 8. 数据与设置（P5）

| 分组 | 条目 | 说明 |
|---|---|---|
| 数据概览 | 计划 N 条 / 课次 N 节 / 学生 N 人 / 游戏 N 款 / 便签 N 条 | 只是计数，不做图表 |
| 备份 | 导出备份文件 | 生成一个 .json 下载到手机「下载」文件夹 |

| 外观 | 浅色 / 深色 / 跟随系统 | 默认跟随系统 |
| | 周起始日：周一 / 周日 | 影响课表与计划页的周视图 |
| 关于 | 版本号 | |
| | 怎么加到桌面 | 一页图文说明（安卓 Chrome：菜单 → 添加到主屏幕） |

## 9. 视觉与手机适配

- **基调**：浅色底 `#F4F5F7`，卡片纯白，圆角 16，阴影非常轻；深色底 `#14161A`，卡片 `#1E2126`。
- **模块识别色**：计划=蓝 `#3B6FE0`，课表=青绿 `#1F9D8B`，娱乐=紫 `#7A5AF0`，备忘=暖黄 `#F2B33D`。只用在图标、标签、状态点上，不大面积刷色。
- **字号**：正文 15，标题 17，辅助 13；行高 1.5。手机上一屏大约放 6-8 条目。
- **适配**：全屏显示（无浏览器地址栏）、顶部状态栏透明、底部避开安卓手势条（安全区内边距）。
- **离线**：所有页面和字体绘图都内置在本地，断网照常打开。

## 10. 三条关键流程走查

**① 上完一节课，顺手记下来**
课表页 → 点这节课的卡 → 点"本节课主要内容"打字 → 点"布置的作业"打字 → 学生那行选"很好" → 点「标记已上课」→ 返回，周视图里这张卡的状态点变绿。
全程 4 次点击 + 两段打字，不超过 1 分钟。

**② 睡前一分钟记件事**
首页 → 备忘输入框 → 打「明天带钥匙」→ 回车 → 出现在便签墙、首页备忘卡同步更新。没有跳页。

**③ 想知道某个学生最近怎么样**
课表 → 右上「学生」→ 点王小明 → 一路往下看：10/25 讲了二次函数、当时状态"很好"；10/18 复习一次函数、状态"正常"。

## 11. 需要你拍板的 4 个交互选择

| # | 问题 | 我的建议 | 备选 |
|---|---|---|---|
| 1 | 课表周视图的排法 | 按天纵向分组（见 5.1） | 7 列网格 |
| 2 | 便签删除方式 | 左滑删除 + 5 秒撤销 | 长按弹菜单确认 |
| 3 | 计划页"昨天没做完的转到今天"提示 | 要（只在当天首次打开时问一次） | 不要，手动搬 |
