## 一、从参考图里提取的 5 个视觉特征

| 特征 | 参考图里的样子 | 我的还原方式 |
|---|---|---|
| **标题栏** | 亮蓝渐变（上浅下深）+ 白字描影 + 右角三个小按钮 | `#0058EE → #3A93FF → #0046CE` 三段渐变，`inset` 顶部高光，`─ □ ×` 三枚 20×18 小按钮（× 为红色） |
| **斜面边框** | 每个区块都有 1px 深蓝外框 + 内侧 1px 白线 | `border:1px solid #7F9DB9` + `box-shadow: inset 0 0 0 1px #fff` |
| **分组标题条** | 浅蓝渐变条 + 深蓝粗体小字 + 左侧小图标 | `linear-gradient(#F6FAFF,#DCE8F8)` + `#0A246A` 12px 粗体 |
| **按钮** | 白→浅蓝渐变、3px 圆角、按下有内阴影 | 三段渐变 + `inset 0 1px 0 #fff`，`:active` 反转为内阴影 |
| **状态栏** | 底部一条细灰蓝条，分格显示状态 | 21px 高，三格：离线状态 / 数据量 / 时间 |

**配色令牌**（已写进预览的 CSS）：

```
标题栏   #0058EE → #3A93FF → #0046CE
窗体底   #ECE9D8（XP 米白）
面板     #FFFFFF，边框 #7F9DB9，内白线
分组条   #D9E7FA → #EDF4FE，字 #0A246A
正文     #0A246A（深蓝） / #4A5A73（次要） / #7A8AA3（弱化）
选中     #316AC5（白字）
状态色   #3FBF52 绿 / #F0A93B 橙 / #B22A2A 红
```

字体：`Tahoma, "MS Sans Serif", 宋体, SimSun, "Microsoft YaHei"`。中文走宋体才有那个年代的味道。

## 二、结构翻译：桌面三栏 → 手机单列

参考图是**桌面布局**（左 234px 分组栏 + 中间主面板 + 右 246px 好友卡）。手机上不能照搬，做了 4 处翻译：

| 参考图 | 手机上变成 | 理由 |
|---|---|---|
| 顶部菜单栏 + 工具条 | **一行 4 个快捷动作**（新增 / 搜索 / 学生 / 课表）+ 右侧头像 | 手机上菜单栏没人用，快捷动作才有价值 |
| 左侧分组栏（好友/置顶/项目/任务） | **底部 5 个标签**（首页/课表/娱乐/备忘/记录），用同样的按钮质感 | 拇指够得着；保留"分组"的视觉（选中态是凹陷按钮） |
| 右侧好友卡（Codex 小蓝 + 等级 + 气泡） | **首页顶部一张"小助手"卡**（头像 + LV 徽章 + 一句话提示） | 手机没有第二栏；助手信息对个人 App 其实有用（今天几节课、哪件事到期） |
| 底部状态栏 | **保留**，压缩到 21px | 它是这套风格最有辨识度的零件之一 |

其余：主面板 → 白底带边框的 `.panel`（带标题条）；列表行 → `.row`（悬停/选中是 XP 蓝）；勾选框 → 13px 方框（不是圆框）。

## 三、和现在这版的差异清单（真做起来要改什么）

**只动样式和少量结构，不动数据和逻辑。**

| 现在 | 改成 | 工作量 |

| 圆角 16px 卡片、无边框、柔和阴影 | 直角 + 1px 蓝框 + 内白线 | CSS 变量 + `.card` 重写（小） |

| 圆形勾选圈 | 方勾选框 | CSS（小） |

## 四、要你拍板的 4 件事

### ① 小助手卡要不要真做？

预览里首页那张「小助手 LV 07 · 上午 09:00 有课…」是我按参考图右侧好友卡翻译的。

- **要**：我用**纯规则**生成文案（不联网、不接 AI），例如「今天 3 节课，最近一节 14:00 小班」「明天 1 个活动截止」「你已经 4 天没备份了」
- **不要**：删掉这张卡，首页更紧凑

### ② 深色模式怎么办？（复古风本来没有深色）

| 方案 | 说明 |
|---|---|
| **A. 做成"夜间 XP"** | 深蓝黑底 + 亮青蓝字 + 深色边框，保持立体感（推荐，风格统一） |
| B. 深色沿用现在的现代风 | 两套风格割裂 |
| C. 直接去掉深色 | 少一块工作量，但晚上刺眼 |

### ③ 字号：13px 够不够？

参考图是 11–12px 的桌面字号，我放大到 **13px**（正文）/ 12px（次要）/ 10.5px（辅助）。
手机上如果觉得小，我可以整体 +1px（但复古感会弱一点）。

### ④ 状态栏留不留？

它很还原，但占 21px 高度。留着会显示「离线可用 / 数据 27 条 / 20:06」。

## 五、我建议的默认答案

如果不想逐条选，我按这个做：

1. **小助手要**（纯规则生成，不联网）
2. 深色做 **夜间 XP**
3. 字号 **13px**（保持）
4. 状态栏 **留**
